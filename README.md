# Calculadora Fiscal

Esta aplicação calcula o IMT e o Imposto do Selo (IS) na aquisição de imóveis em Portugal.

Permite efectuar cálculos para liquidações únicas ou múltiplas e contempla as opções de IMT normal e IMT Jovem.

Os cálculos abrangem:
- prédios destinados a Habitação Própria e Permanente;
- prédios destinados a Habitação Secundária;
- prédios rústicos;
- prédios urbanos não habitacionais, designadamente comerciais, escritórios e terrenos para construção.
